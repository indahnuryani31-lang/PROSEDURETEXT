Materi: Procedure Text

1. Definition & Social Function

Procedure Text is a text that gives instructions on how to do or make something step-by-step.

Social Function: To explain/guide the reader on how to achieve a goal (e.g., How to Manage Personal Financial Expenses effectively).

2. Generic Structure
  • Goal/Aim: Outlines the main goal (e.g., How to Create a Monthly Budget).
  • Materials/Equipment: Things needed (e.g., Notebook, Budgeting App, Bank Records).
  • Steps/Methods: Sequential instructions (e.g., First, Next, Then, Finally).
3. Language Features
  • Use Simple Present Tense.
  • Use Imperative Sentences (e.g., Calculate your income, Save 20% of money).
  • Use Action Verbs (e.g., track, set, divide, pay).
  • Use Temporal Connectives (e.g., First, Second, After that, Finally).
